# Product Care Instructions

Laptops

- Keep vents clean.
- Avoid overheating.
- Update OS regularly.
- Charge between 20% and 80% for better battery health.

Smartphones

- Avoid extreme temperatures.
- Use certified chargers.
- Keep software updated.
- Enable Find My Device.

Smart Watches

- Clean sensors weekly.
- Avoid saltwater exposure.
- Charge using original charger.

Earbuds

- Clean ear tips regularly.
- Store in charging case.
- Avoid moisture.
